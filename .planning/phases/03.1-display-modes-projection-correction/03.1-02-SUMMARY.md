# Phase 3.1 Plan 02: Cylinder Correction Shader Summary

**Inverse cylindrical projection shader with staging FBO, pre-warps flat-rendered content so it appears geometrically correct on OpenXR cylinder composition layers**

## Performance

- **Duration:** 3 min
- **Started:** 2026-02-22T07:01:51Z
- **Completed:** 2026-02-22T07:04:35Z
- **Tasks:** 2
- **Files modified:** 4

## Accomplishments
- Staging FBO infrastructure: per-eye staging textures and FBOs created during renderer init, destroyed during teardown, preventing GL read-write feedback
- Cylinder correction GLSL 330 core shader with inverse cylindrical projection math (tan(theta)/tan(halfAngle) for X, centered.y/cos(theta) for Y)
- Post-processing integrated in VR_EndFrame: blit swapchain to staging, draw staging to swapchain with correction, only when display surface is Curved
- Vertex-less fullscreen triangle using gl_VertexID with dummy VAO for core profile compatibility

## Files Created/Modified
- `Common/VR/VRBase.h` - Added StagingTexture, StagingFBO, StagingWidth, StagingHeight fields to ovrRenderer struct
- `Common/VR/VRFramebuffer.h` - Added ovrRenderer_CreateStagingFBO/DestroyStagingFBO declarations
- `Common/VR/VRFramebuffer.cpp` - Implemented staging FBO create/destroy, hooked into renderer lifecycle, zero-init in ovrRenderer_Clear
- `Common/VR/VRRenderer.cpp` - Added cylinder correction shader (VS+FS), InitCylinderCorrectionShader, ApplyCylinderCorrection, VR_EndFrame integration gated on VR_SURFACE_CURVED, cleanup in VR_DestroyRenderer

## Decisions Made
- 90-degree central angle (PI/2) matches the cylinder layer's centralAngle constant -- ensures shader correction and runtime warping are complementary
- Dummy VAO created alongside shader program -- required by OpenGL core profile for glDrawArrays even with vertex-less draw
- GL_SRGB8_ALPHA8 used for staging texture to match swapchain format and preserve color space
